# 升级后重新核对

升级 dsh 之后要重新核对什么、按什么顺序。

## 三级分级

按「**变化触发条件**」分级，不按重要性分级：

| 级 | 含义 | 写法 |
|---|---|---|
| **S 稳定** | 有上游成文规则，或跨 rc 实测不变 | 可写死断言，**必须挂出处**（`path:line @ commit`；指不到出处就降级为 R） |
| **R 随 rc 变** | 随宿主 rc 变化 | 只写读取命令，不写值 |
| **D 随发行版或机器变** | 随发行版、机器或 profile 变 | 写成尖括号槽位 + 发现命令 |

长度与形态纪律（入口与每册的上限）是 S 级，但它的 owner 在入口。

按这套分级，peer 区间是真闸门、属 R 级：只写读取命令，不写区间值；能救命的只有 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-*` 那族。

## 最反直觉的一条

宿主源码里的**清单型常量**最容易误判成 S：它们看着像「契约」，其实随 rc 增删（`requiredStartupEntryIds` 一类就是典型判级案例）。判级办法只有一条——**用读取命令现读，把成员列出来，再决定它是不是 S**；成员不进正文。

## 五条表达规则

1. 读法**就地**：值型断言的紧邻下一行必须是读取命令，不搬到别的文件。
2. R 级一律改写成「规则 + 读法」。
3. S 级必须挂 `path:line @ commit`；指不到出处就降级为 R，行号不进正文。
4. D 级一律写成尖括号槽位（`<cli>` 这类）+ 发现命令。
5. 快照**两列并列**（上游 commit + 本机版本），且对比前**规范化换行**——裸哈希比较会产生**假漂移**。

## 升级后再核对 6 步 checklist

| 步 | 命令 | 期望 | 失败意味着 |
|---|---|---|---|
| 0 | 冻结快照两列（上游 commit + 本机版本） | 两列都写下来 | 只写一列 ⇒ 后面判断不出漂移方向 |
| 1 | 重读版本面：`node "<cli>" --version` 与 `node "<skill-directory>/scripts/dsh-env.mjs"` | 版本与 `dsh.verified` 一致 | 版本读不到 ⇒ 先修环境发现 |
| 2 | 重读契约真源：manifest 类型定义 | 字段集合与正文一致 | 出现新字段或字段消失 ⇒ 回写受影响的册 |
| 3 | 重看页面与作者 skill | 页面路径与仓库一致 | 站点缺页或比仓库旧 ⇒ 判定回到仓库 + commit |
| 4 | 重验行为（一次性 profile） | 装配与 mount 的观察面都命中，且 stderr 里不出现 `pending (waiting for service:` | 见下面「步骤 4 的三个已实测细节」 |
| 5 | 重验 skill 自身机制（入口形态、指针、长度） | 断言全部命中 | 形态漂移 ⇒ 先修入口 |
| 6 | 回写：把新事实写进对应 owner 册，并更新快照两列 | 每处改动都指回一条读法 | 没回写 ⇒ 下次还得重查 |

## 步骤 4 的三个已实测细节

- `--dump-config-schema` 的退出码由 `complete` 布尔量决定，不是「问题行数」，也不是「JSON 可用性」：warning 再多也不让它变 1，而一条 `partial` 条目即使没有 error 也会让它变 1。⇒ 要比的是问题条目与 indices，不是退出码。
- 它**不会自动建 profile**。
- `--dump-default-config` 看不到 patch 未命中告警（它跳过用户层与 overlay）。

## 步骤 3 的两个已实测坑

- 站点**不是全量**：`upgrade-guide` 这类路径会 404 ⇒ 升级指南要直读仓库。
- 站点**未必与 master 同步**：页面路径只能当线索，判定回到仓库 + commit。

## 案例库（只给症状与读法）

| 症状 | 读法 |
|---|---|
| 字段死过：manifest 里某个字段读不到消费者 | 回步骤 2，用类型定义现读确认它还在不在 |
| 符号不存在：某个导出在发行物里找不到 | 在宿主包目录里按符号搜索，确认是改名还是移除 |
| 行号漂移：同一条断言在同一个 rc 内两次测量不一致 | 规范化换行后重比快照两列，确认是不是假漂移 |

## 边界

- 落后量**未复算**：正文不写「本机落后上游多少 commit」这类数字，只给读法。
- 多段并列区间（跨 0.x minor 的 peer 区间写法）**未实测**：只给形状，不给结论。
- 站点差集**未全量 diff**：只给两条已实测坑，不给完整清单。
- Cordis 侧行号**无法对齐**（vendored 代码与上游 monorepo 的行号不同源）⇒ 引 Cordis 实现时只给包名与相对路径，不给行号。
- 自己复算的办法：跑 `node "<skill-directory>/scripts/dsh-env.mjs"` 与 `node "<cli>" --version`，把快照两列重写一遍再对比。
